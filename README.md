# Riftsight

**Conquer. Hold. Understand.**

App de fã, gratuito e não oficial, para registrar partidas de Riftbound, guardar a história dos teus decks e entender onde cada um ganha e onde precisa melhorar.

- Site: https://marcusazevd.github.io/riftsight/
- App web: [`app/`](app/)
- APK Android: [`download/Riftsight.apk`](download/Riftsight.apk) (Android 10+)
- Privacidade: [`privacy.html`](privacy.html)

Os dados ficam só no aparelho do jogador. Não há servidor, conta, anúncio nem coleta de dados.

## English

Riftsight is a free, non-commercial fan app for the Riftbound TCG: a personal match journal with deck versions and personal stats. It does not collect data from other players and does not publish metagame-wide deck or card win rates.
